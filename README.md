> 嵌入式项目（2026.07.14 – 2026.07.27）：基于 ST 标准外设库（非 HAL），从点亮一颗 LED 到三大解锁方式系统集成，以 9 个递进子工程完整记录开发过程。密码键盘 + 光学指纹 + 电容触摸三种身份验证方式，OLED 交互 + 语音播报 + 电机开锁 + 串口日志。

## ✨ 功能特性

- 🔢 **密码解锁** — BR3116（CY8CMBR3116）电容触摸 12 键输入，按 `#` 确认，`strcmp` 比对
- 🫆 **指纹解锁** — MG200 光学指纹模块（USART6），采集 / 注册 / 1:N 比对全流程
- 📟 **射频触摸按键** — 电容触摸矩阵模拟刷卡输入，软件 I2C 驱动
- 🖥 **OLED 人机交互** — ST7789VM 240×240，RGB565，中英文混显 + 图片显示
- 🔊 **语音播报** — 单线串行协议，"欢迎回家 / 验证失败 / 密码错误"等提示音
- 🚪 **电机开锁** — H 桥正反转控制，开锁 1 秒后自动停止
- 🔒 **安全锁定** — 连续 3 次密码错误触发 30 秒锁定（OLED 倒计时 + 红色 LED + 串口日志 + 按键屏蔽）
- 📡 **串口日志** — USART1 115200，printf 重定向实时输出开锁事件

## 🏗 系统架构

采用"主控 + 外设模块"的经典三层架构，全部外设基于 GPIO / USART / 软件模拟 I2C / 软件模拟 SPI 驱动：

```
┌────────────────────── 输入层 Input ──────────────────────┐
│  BR3116 电容触摸矩阵(12键)    MG200 光学指纹    独立按键    │
│        └─ 软件 I2C ─┘         └─ USART6 ─┘     └─ GPIO ─┘ │
├────────────────── 控制层 Control: STM32F401RET6 ──────────┤
│  密码比对 strcmp  │  指纹 1:N 比对  │  3次错误 → 30s 锁定   │
├────────────────────── 输出层 Output ──────────────────────┤
│  OLED 240×240   语音播报   LED/电机开锁   USART1 串口日志  │
└───────────────────────────────────────────────────────────┘
```

## 🚀 快速开始

### 环境要求

- **Keil MDK-ARM v5**（需已安装 STM32F4xx 设备支持包 `Keil.STM32F4xx_DFP`）
- **ST-Link** 调试器 + STM32F401RET6 开发板（推荐配套《XYD_SmartLock_V2.pdf》的 XY-D 智能门锁开发板）
- 串口调试助手（XCOM 等，115200-8-N-1）

### 编译与烧录

```

1. 用 Keil 打开 `PROJECT\09-mg200\Smart_Lock.uvprojx`（最终完整版，包含全部功能）
2. `F7` 编译 → 确认 **0 Error(s)**（工程已配置好 `..\..\LIB` 相对路径，克隆即可编译）
3. ST-Link 连接开发板 → `F8` 下载固件，板子自动复位运行

### 功能验证

| 验证项 | 操作 | 预期现象 |
|---|---|---|
| 串口日志 | 打开串口助手 115200 | 输出各模块"初始化完成"日志 |
| 密码开锁 | 触摸按键输入 `123` → `#` | 语音"欢迎回家" + 绿灯 + 电机开锁 |
| 密码错误 | 连续输入错误密码 3 次 | 红色 LED + 30 秒锁定倒计时（OLED 显示） |
| 指纹开锁 | 按压指纹传感器 | 比对成功后语音提示 + 开锁 |

## 📚 分阶段构建路径:

9 个子工程按"基础验证 → 模块驱动 → 系统集成"递进，每个阶段独立可编译:

| 阶段 | 工程 | 模块 | 关键知识点 |
|:---:|---|------|------|
| 1 | `01-led` | LED 呼吸灯 | GPIO 推挽输出、引脚宏封装、PWM 模拟呼吸 |
| 2 | `02-key` | 独立按键 | 浮空输入、软件消抖、状态机扫描 |
| 3 | `03-motor` | H 桥电机 | 正反转时序、上电防误触发 |
| 4 | `04-usart` | USART1 串口 | 115200 配置、fputc 重定向 printf |
| 5 | `05-tim` | TIM2 延时 | PSC / ARR 时基、查询式 μs/ms 延时 |
| 6 | `06-voice` | 语音播报 | 单线串行协议、BUSY 轮询 |
| 7 | `07-lcd` | OLED 显示 | 软件 SPI、RGB565、字库查表、中英混显 |
| 8 | `08-br3116` | 电容触摸 | 软件 I2C、寄存器配置、按键映射、密码比对 |
| 9 | `09-mg200` | 指纹识别 | USART6 中断 + IDLE、自定义帧协议、1:N 比对 |

## 🔌 硬件连接

| 模块 | 信号 | STM32 引脚 | 通信方式 |
|---|---|---|---|
| LED 指示灯 | 红 / 绿 | PB8 / PB9 | GPIO（低电平点亮） |
| 电机 H 桥 | IA / IB | PB4 / PB3 | GPIO |
| BR3116 电容触摸 | SCL / SDA / RST | PB6 / PB7 / PA1 | 软件 I2C |
| MG200 指纹 | TX / RX / DETECT / PWR | PC6 / PC7 / PC0 / PC1 | USART6 |
| OLED（ST7789VM） | SCLK / MOSI / CS / DC / RST / LEDK | PB13 / PB15 / PB12 / PB14 / PB10 / PB1 | 软件 SPI |
| 语音模块 | DATA / BUSY | PC5 / PC4 | 单线串行协议 |
| 串口日志 | TX / RX | PA9 / PA10 | USART1（115200） |
| 独立按键 | KEY1 / KEY2 | PA0 / PC13 | GPIO 输入 |
